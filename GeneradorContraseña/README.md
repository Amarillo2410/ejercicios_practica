# 3. Generador de contraseñas seguras

En este reto debes crear un programa en **C# para consola** que genere contraseñas aleatorias.

Las contraseñas generadas deben cumplir las siguientes condiciones:

- Tener una longitud **entre 15 y 87 caracteres**.
- Contener **al menos una letra mayúscula**.
- Contener **al menos una letra minúscula**.
- Contener **al menos un dígito**.
- Contener **al menos un carácter especial**.

Los caracteres especiales permitidos son únicamente los siguientes:

! @ # $ % & * ? + = - /
