# 4. Contar frecuencia de caracteres en una cadena

Debes crear un programa en **C# para consola** que reciba una cadena de texto y calcule la frecuencia con la que aparecen sus distintos caracteres alfanuméricos, es decir, **letras y números**.

El resultado debe devolverse en una colección de objetos, donde cada objeto tenga los siguientes campos:

- `Car`: el carácter encontrado
- `Veces`: la cantidad de veces que aparece

La colección resultante debe estar **ordenada alfabéticamente por el carácter**.

### Reglas del problema

- No se debe diferenciar entre **mayúsculas y minúsculas**.
- No se debe diferenciar entre **vocales con tilde y sin tilde**.
- Solo se deben contar **letras y números**.
- El resultado debe generarse sin modificar el texto original.
