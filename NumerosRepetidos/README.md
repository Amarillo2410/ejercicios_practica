# 2. Detectar números repetidos en un arreglo

Crea un programa en **C# para consola** que implemente una función capaz de recibir un arreglo de números enteros positivos y devolver otro arreglo con los valores que se encuentran repetidos.

Por ejemplo, si se recibe el arreglo:

```
[10, 3, 5, 3, 10]
```

la función deberá retornar:

```
[3, 10]
```

porque esos son los números que aparecen más de una vez en el arreglo original.
